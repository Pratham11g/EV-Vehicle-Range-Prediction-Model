# EV Vehicle Range Prediction

## 📌 Project Overview

A machine learning project for predicting the driving range of electric vehicles using vehicle specifications and machine learning regression models.

## 🎯 Objective

The objective of this project is to develop and evaluate machine learning models capable of accurately predicting EV range based on vehicle characteristics.

## 🤖 Machine Learning Models

The following regression models were evaluated:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Random Forest
- Gradient Boosting

## 📊 Results

Gradient Boosting achieved the best performance with an R² score of **0.943** on the primary dataset.
